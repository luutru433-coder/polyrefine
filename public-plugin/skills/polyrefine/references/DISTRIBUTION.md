# Distribution (R08)

Maintain one versioned rule source in core/. Generate the skills-only submission and the Portable Pack from that source. The submission must have no MCP server, app connections, extension UI, third-party login, backend, storage or external translation service. Do not claim public approval or compatibility with a particular plan before live verification.

The Portable Pack runs as Project instructions in a user's own project or as a standalone chat prompt; it requires no plugin upload, external API key or plugin-creation rights. Do not recommend shared projects for private material. Explain Memory choices without promising absolute isolation. Verify both distributions separately on a real Free account where the corresponding feature is available.
