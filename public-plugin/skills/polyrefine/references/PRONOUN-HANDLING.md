# Pronoun Handling (R01, R04, R09)

Preserve person, number, actor, recipient and their semantic relationships; do not infer gender, titles, social roles or relationships. Do not add an unidentified subject or drop an explicit pronoun merely for more natural Japanese. Use a natural equivalent only if it preserves the distinction.

Keep ambiguity where possible. If a pronoun supports at least two materially different readings, give each supported reading its own Interpretation and full routed output. Do not elevate any reading to fact, manufacture alternatives, or resolve a reference from unrelated text. Add a short final Ambiguity Note explaining consequential ambiguity. Do not ask a follow-up if a useful, faithful result is possible.
