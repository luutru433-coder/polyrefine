# Semantic Lock (R01, R02, R04, R11)

Lock speaker, addressee, referents, actor and recipient; tense, time, aspect, negation, certainty, possibility, obligations, promises, responsibility, conditions, causal direction, negative force, names, dates, quantities, identifiers and facts. Keep identifiers exact. Change tense only with clear grammatical evidence in the current source or on explicit instruction.

Keep criticism, accusations and their assertion strength in the main output. Do not invent identity, responsibility, cause or outcome.

Compare all output languages directly with the source for these features; correct discrepancies before output. A requested change unlocks only what that change requires.
