# Quick Start

## Set up your own ChatGPT Project

1. Select **New project** in ChatGPT and name it PolyRefine Translator. Keep it private; do not use a shared Project for private or customer text.
2. At creation, choose **project-only memory** if available and you want to limit what context can be referenced across projects. Project-only memory can still reference chats within that project. Check your ChatGPT Memory settings and your workspace policies; options vary.
3. In the Project menu, open **Project settings**, paste the contents of [PROJECT-INSTRUCTIONS.md](PROJECT-INSTRUCTIONS.md) into Project instructions and save.
4. Start a chat in the Project, paste text, then compare the result with [TEST-EXAMPLES.md](TEST-EXAMPLES.md).

## Use any chat

Copy [COMPACT-PROMPT.txt](COMPACT-PROMPT.txt) into a fresh ChatGPT conversation, then send your text. To limit use of previous conversations, use a Temporary Chat when appropriate. Neither the prompt nor Project instructions disable ChatGPT Memory, history or retention. Do not paste sensitive material if your account settings or policies do not permit it.

No plugin upload, API key or external login is required for the Portable Pack.
